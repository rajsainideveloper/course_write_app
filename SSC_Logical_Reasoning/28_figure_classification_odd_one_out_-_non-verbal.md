# Figure Classification (Odd One Out - Non-Verbal)

> The visual discriminant: isolating the one figure that violates the unifying rule of a set. This is not about finding differences; it is about defining the exclusive property that four figures share and one does not.

## Chapter 1: The Foundations of Visual Classification

### Section 1 | What Is Figure Classification?

Figure classification presents a set of five figures (usually labeled A, B, C, D, E) and asks you to identify the "odd one out"—the figure that does not share the common property or rule that unites the other four.

**The Core Principle**: The four correct figures must share a *precise, objective, and exclusive* visual property that the odd one violates. This property can be based on shape, size, orientation, arrangement, shading, or any combination of these.

**The Cognitive Shift**: Do not look for *any* difference. Look for the *single rule* that four figures obey and one does not. If your rule makes two figures odd, it is too broad. If your rule requires multiple exceptions, it is too narrow.

[alert type="danger"]
**The Overfitting Trap**: Students often find creative but invalid rules that make any figure the odd one. The exam always favors the *simplest* rule that fits four figures exclusively. If your rule takes more than a sentence to explain, it is likely wrong.
[/alert]

### Section 2 | The Classification Framework

| Property Category | What to Examine | Example Mismatch |
| :--- | :--- | :--- |
| Shape | Number of sides, curves, symmetry | 4 figures are polygons, 1 has curves |
| Size | Relative dimensions, scale | 4 figures are large, 1 is small |
| Orientation | Rotation angle, direction | 4 figures point up, 1 points down |
| Shading | Filled, striped, dotted | 4 are shaded, 1 is unshaded |
| Arrangement | Position of elements, pattern | 4 have dots on the right, 1 has dot on the left |
| Count | Number of lines, shapes, corners | 4 have 3 lines, 1 has 4 lines |

## Chapter 2: Shape and Size Based Mismatches

### Section 1 | Shape Properties

The most common classification rule involves the *number of sides* or the *type of shape*. Four figures may be triangles, and one is a square. Or four may be closed shapes and one is open.

**The Trap**: Some shapes may appear to have different numbers of sides due to overlapping lines. Count the distinct sides of the outer boundary.

**Example**:
- Figures: Triangle, Square, Pentagon, Hexagon, Circle.
- Odd one: Circle (not a polygon).

### Section 2 | Size Mismatches

Size mismatches occur when four figures share a common scale and one is significantly different.

**Example**:
- Four large circles, one small circle.
- The odd one is the small circle.

**The Trap**: Size can be relative. Sometimes the odd figure is the one that does not fit a *proportional* pattern (e.g., the ratio of height to width is different).

[alert type="success"]
**The Dimension Count**: For shape-based classification, count the number of lines, curves, or corners. The odd one will often have a different count.
[/alert]

[flashcards title="Shape Properties Quick Reference"]
| Property | Check For | Example Odd One |
| :--- | :--- | :--- |
| Number of Sides | Triangle (3), Square (4), etc. | One figure has different sides |
| Closed vs Open | Figure is complete | One figure is not closed |
| Straight vs Curved | All lines are straight | One has curves |
| Symmetry | Vertical, horizontal, rotational | One figure is asymmetric |
| Regular vs Irregular | All sides equal | One figure has unequal sides |
[/flashcards]

## Chapter 3: Rotation and Orientation Mismatches

### Section 1 | Directional Orientation

When all figures share a common orientation (e.g., all point upward), the one that points in a different direction is the odd one.

**Example**:
- Four arrows pointing up, one pointing down.
- Odd one: Arrow pointing down.

### Section 2 | Rotation Angle

Sometimes the figures are all rotated versions of the same shape, but one is rotated by a different angle than the others.

**Example**:
- Four squares rotated by 0°, 90°, 180°, 270° (all valid rotations), and one square rotated by 45°.
- Odd one: The 45° square.

[alert type="warning"]
**The Multiple Rotation Rule**: If multiple figures are rotated, they may all be valid rotations of the same base shape. The odd one may be the one that is not a valid rotation of the base shape.
[/alert]

[flashcards title="Orientation Rules"]
| Orientation Type | Check For | Example Odd One |
| :--- | :--- | :--- |
| Pointing Direction | Up, down, left, right | One points differently |
| Rotation Angle | 0°, 90°, 180°, 270° | One has a different angle |
| Reflection | Mirrored versions | One is not a mirror |
| Axis Alignment | Horizontal, vertical | One is diagonal |
[/flashcards]

## Chapter 4: Pattern and Arrangement Mismatches

### Section 1 | Position of Elements

When figures contain internal elements (dots, lines, smaller shapes), the *position* of these elements often determines the rule.

**Example**:
- Four figures have a dot in the top-left corner, one has a dot in the bottom-right.
- Odd one: The figure with the dot in a different position.

### Section 2 | Pattern of Elements

The arrangement of multiple elements may follow a pattern that one figure breaks.

**Example**:
- Four figures have two circles and one square. One figure has two squares and one circle.
- Odd one: The figure with the wrong count of shapes.

[alert type="info"]
**The Position Grid**: For figures with multiple internal elements, imagine a 3×3 grid overlay. Track the positions of each element. The odd one will have an element in a position that none of the others share.
[/alert]

[flashcards title="Pattern and Arrangement Rules"]
| Rule Type | Check For | Example Odd One |
| :--- | :--- | :--- |
| Element Position | Where elements are located | One dot is in a different position |
| Element Count | Number of internal elements | One has different count |
| Element Type | Type of internal element | One has different shape inside |
| Relative Position | Arrangement of multiple elements | One has a different order |
| Symmetry Pattern | Pattern is symmetric | One breaks the symmetry |
[/flashcards]

[example]
**Question:** Five figures show a circle with a dot inside. In four figures, the dot is in the center. In one figure, the dot is at the top. Which is the odd one?
**Solution:**
Step 1: Identify the common rule: The dot is in the center.
Step 2: Find the figure that violates this rule: The figure with the dot at the top.
**Final Answer:** Figure with the dot at the top.
[/example]
