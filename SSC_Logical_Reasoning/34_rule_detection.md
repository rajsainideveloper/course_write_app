# Rule Detection

> The visual algorithm: distilling the governing principle that unifies a set of figures. This is not about recognizing individual images; it is about abstracting the common structural rule that defines the entire set.

## Chapter 1: The Foundations of Rule Detection

### Section 1 | What Is Rule Detection?

Rule detection questions present a set of figures (usually 4 or 5) that share a common visual property or transformation rule. Your task is to identify the underlying rule and then either select the figure that follows the rule, or identify the figure that violates it.

**The Core Principle**: Every figure in the set is generated by a common rule. This rule may involve rotation, reflection, addition, deletion, movement, arrangement, or a combination of these. The rule must be applicable to all figures in the set.

**The Cognitive Shift**: Do not look for differences between the figures. Look for the *common transformation* that links them. The figures are variations of a base figure; the rule explains how each variation is derived.

[alert type="danger"]
**The Overgeneralization Trap**: A rule that works for three figures may fail for the fourth. Test your proposed rule against *all* figures in the set. If it fails for one, your rule is incorrect or incomplete.
[/alert]

### Section 2 | The Rule Detection Protocol

1. **Examine each figure** in the set. Note the elements present, their positions, orientations, and any patterns.
2. **Identify what changes** from one figure to the next. Is it rotation? Addition? Deletion?
3. **Identify what stays the same**. The constant element is often the key to the rule.
4. **Formulate a rule** that explains the transition from one figure to the next.
5. **Test the rule** on all figures. If it works consistently, you have found the rule.
6. **Apply the rule** to find the missing figure or identify the odd one out.

## Chapter 2: Visual Rules

### Section 1 | Rotation and Reflection Rules

The most common visual rules involve rotation or reflection:
- **Rotation**: The figure rotates by a fixed angle (90°, 180°, 270°) at each step.
- **Reflection**: The figure is mirrored across a vertical, horizontal, or diagonal axis.

**Example**: A set of arrows rotates 90° clockwise each step: Up → Right → Down → Left → Up.

### Section 2 | Addition and Deletion Rules

Some rules involve adding or removing elements:
- **Addition**: A new element appears at each step.
- **Deletion**: An element is removed at each step.
- **Alternating**: Addition and deletion alternate.

**Example**: A set of circles: 1 circle, 2 circles, 3 circles, 4 circles. The rule is "add one circle each step."

### Section 3 | Movement Rules

Elements may move within the figure:
- **Linear**: Move left, right, up, or down.
- **Diagonal**: Move along a diagonal.
- **Circular**: Move around a center.

[alert type="success"]
**The Element Tracking**: For movement and addition/deletion rules, track the identity of each element. If elements are added or removed, note the sequence. If elements move, track their positions.
[/alert]

[flashcards title="Visual Rule Types"]
| Rule Type | Description | Example |
| :--- | :--- | :--- |
| Rotation | Figure turns by a fixed angle | Arrow rotates 90° CW |
| Reflection | Figure is mirrored | Arrow flips horizontally |
| Addition | Element is added | Dot appears |
| Deletion | Element is removed | Line disappears |
| Movement | Element changes position | Dot moves to the right |
| Combination | Two or more rules applied | Rotate and add a line |
[/flashcards]

[example]
**Question:** A set of figures shows a square with a line. Figure 1: line horizontal. Figure 2: line vertical. Figure 3: line horizontal. Figure 4: ?. What is the rule?
**Solution:**
Step 1: Identify the changes: The line alternates between horizontal and vertical.
Step 2: The rule: The line rotates 90° each step, alternating.
Step 3: Figure 3 has a horizontal line, so Figure 4 should have a vertical line.
**Final Answer:** Square with a vertical line.
[/example]

## Chapter 3: Similarity of Figures

### Section 1 | Identifying Similarity Patterns

Similarity rule detection involves finding the common property shared by all figures in a set. The property could be based on shape, size, orientation, number of elements, or any other visual feature.

**Example**: All figures are composed of three lines. The odd one might have four lines.

### Section 2 | The Odd-One-Out Variation

Sometimes the task is to identify the figure that does *not* follow the rule. This requires first identifying the common rule, then finding the exception.

**The Method**:
1. Identify the common rule shared by most figures.
2. Test each figure against the rule.
3. The figure that violates the rule is the odd one.

[alert type="warning"]
**The Multiple Rule Possibility**: There may be more than one plausible rule. The correct rule is the one that includes the most figures and is the simplest. If two rules are equally plausible, the question may be ambiguous; the exam will avoid this.
[/alert]

[flashcards title="Similarity Rules"]
| Similarity Type | Description | Example |
| :--- | :--- | :--- |
| Shape | All figures are same shape | All are triangles |
| Size | All figures are same size | All are large |
| Orientation | All figures face same direction | All point up |
| Count | All have same number of elements | All have 3 lines |
| Arrangement | All have same pattern | All have a dot in the center |
[/flashcards]

[example]
**Question:** Which figure is the odd one out? Figures: Circle, Square, Triangle, Circle with a dot, Square with a dot.
**Solution:**
Step 1: Identify the common rule: All are shapes, but four have no dot and one has a dot? Actually, Circle and Square have no dot; Circle with dot and Square with dot have dots; Triangle has no dot. The common rule could be "all are basic shapes." But Circle with dot and Square with dot are not basic shapes—they have additions. The odd one might be Triangle? Or it might be Circle with dot? Let's re-evaluate: If the rule is "shapes without dots," then Circle, Square, Triangle are in, and Circle with dot, Square with dot are out. If the rule is "all are shapes," then all are in. The intended rule is likely "shapes without internal elements." So the odd ones are Circle with dot and Square with dot. But there is only one odd one? The question may be flawed. In a well-formed question, there would be four figures following a rule and one violating it.
**Final Answer:** Cannot be determined from the given figures; the question is ambiguous.
[/example]

## Chapter 4: Pattern Identification

### Section 1 | Pattern Recognition Strategies

Pattern identification involves recognizing a repeated sequence or structure across figures. The pattern may be based on the arrangement of elements, the sequence of colors, or the progression of shapes.

**The Strategy**:
1. **Look for repetition**: Does a shape or arrangement repeat?
2. **Look for progression**: Does the pattern change in a predictable way?
3. **Look for symmetry**: Is the pattern symmetric?

### Section 2 | The Combination Rule

Often, the rule is a combination of two or more simpler rules. For example, "rotate 90° clockwise and add a dot" or "move one step right and change color."

**The Trap**: Students often stop at the first rule they find, missing the second rule. Always check if a combination of rules explains the pattern more completely than a single rule.

[alert type="info"]
**The Completeness Check**: A rule is complete if it explains all aspects of the figures. If there is any unexplained variation, the rule is incomplete.
[/alert]

[flashcards title="Pattern Identification Checklist"]
| Aspect | Check For | Example |
| :--- | :--- | :--- |
| Shape | Same or changing | All circles, or circle→square→triangle |
| Size | Same or changing | All small, or small→medium→large |
| Orientation | Same or changing | All up, or up→right→down |
| Color | Same or changing | All black, or black→gray→white |
| Position | Same or changing | All centered, or center→left→right |
[/flashcards]

[example]
**Question:** Figures show a sequence: Circle, Square, Triangle, ?. What is the next figure?
**Solution:**
Step 1: Identify the pattern: Circle → Square → Triangle. The shapes have 0, 4, 3 sides? Not a clear progression.
Step 2: Alternative pattern: The shapes are changing from curved to straight, or from simple to complex.
Step 3: If the pattern is "add one side each step" (circle has infinite sides, then 4, then 3... not consistent). If the pattern is "shapes with increasing number of vertices"? Circle (0), Square (4), Triangle (3) — not increasing.
Step 4: If the pattern is based on the number of lines: Circle (1 curve), Square (4 lines), Triangle (3 lines) — not consistent.
Step 5: The most common pattern for circle, square, triangle is "shapes with decreasing symmetry" or "shapes in a cycle." The next figure might be a pentagon or a circle again.
Step 6: Without more information, the pattern is ambiguous.
**Final Answer:** Cannot be determined from a single sequence.
[/example]

- A) Triangle
- B) Square

- D) Circle (Correct: All others are polygons; circle is not.)
- E) Hexagon

- A) 5 lines (Correct: The pattern is adding one line each step.)
- B) 4 lines
- C) 3 lines
- D) 6 lines

Q: A set of figures shows a square with a diagonal line: no line, diagonal top-left to bottom-right, diagonal top-right to bottom-left, ?. What is the next figure?
- A) No line (Correct: The pattern alternates: no line, diagonal 1, diagonal 2, no line.)
- B) Diagonal 1
- C) Diagonal 2
- D) Both diagonals
