Unlike analogy, which requires finding a pair with an identical relationship, classification demands you detect the single item that violates a consistent rule shared by the others. This is fundamentally a test of negative logic.The cognitive architecture here is distinct. You are not matching relationships; you are constructing a rule set that applies to all but one elements. The correct classification solution is the one where the relationship you identify is =simultaneously true for four items and false for exactly one=.The Overarching Principle:You must identify the deepest commonality. The most common error in classification is selecting the item that is superficially different.
