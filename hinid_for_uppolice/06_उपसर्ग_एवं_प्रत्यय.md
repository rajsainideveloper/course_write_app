# उपसर्ग एवं प्रत्यय

शब्द निर्माण की वह आधारशिला, जिसके बिना हिंदी व्याकरण की संरचना और शब्दावली का विस्तार असंभव है।

## Chapter 6: उपसर्ग एवं प्रत्यय (Prefixes and Suffixes)

### Section 1 | उपसर्ग: परिभाषा, आवश्यकता एवं विशेषताएँ

शब्दों के निर्माण में शब्दांशों की अत्यंत महत्वपूर्ण भूमिका होती है। भाषा को गतिशील, व्यापक और समर्थ बनाने के लिए नए-नए शब्दों की आवश्यकता निरंतर बनी रहती है। इस शब्द-रचना प्रक्रिया में शब्दांशों का विशेष योगदान होता है, जो मूल शब्दों के आगे या पीछे जुड़कर उनके अर्थ में परिवर्तन या विशिष्टता ला देते हैं।

=उपसर्ग दो शब्दों 'उप' (समीप या आगे) और 'सर्ग' (सृष्टि करना या जोड़ना) के मेल से बना है जिसका शाब्दिक अर्थ किसी शब्द के समीप आकर नया शब्द बनाना है=।

[alert type="success"]
**Important Fact:** उपसर्ग हमेशा मूल शब्द के **आरंभ (Prefix)** में जुड़ते हैं और जुड़कर उसके अर्थ को बदल देते हैं या उसमें एक नई विशेषता उत्पन्न कर देते हैं।
[/alert]

उपसर्गों की प्रमुख विशेषताएँ निम्नलिखित हैं:

- ये स्वतंत्र शब्द नहीं बल्कि **शब्दांश (Affixes)** होते हैं, जिनका प्रयोग स्वतंत्र रूप से वाक्य में नहीं किया जा सकता।
- ये मूल शब्द के पूर्व में लगकर उसके अर्थ को पूर्णतः बदल सकते हैं या उसके अर्थ में एक विशेष दिशा जोड़ सकते हैं।
- हिंदी में तीन मुख्य स्रोतों से उपसर्ग आए हैं: **संस्कृत के उपसर्ग (Sanskrit Prefixes)**, **हिंदी के अपने उपसर्ग (Native Hindi Prefixes)**, और **विदेशी भाषा के उपसर्ग (Foreign Prefixes)**।

### Section 2 | संस्कृत के उपसर्ग

संस्कृत भाषा से हिंदी में ज्यों के त्यों (तत्सम रूप में) प्रयुक्त होने वाले उपसर्गों की संख्या 22 मानी जाती है। उत्तर प्रदेश पुलिस कांस्टेबल परीक्षा में इनसे संबंधित प्रश्न प्रायः शब्दों के विच्छेद या उनके अर्थ पर आधारित होते हैं।

प्रमुख संस्कृत उपसर्गों की तालिका नीचे दी गई है:

| उपसर्ग |अर्थ / विशेषता |उदाहरण |
| **प्र** |आगे, अधिक, उत्कृष्टता |प्रगति, प्रबल, प्रयत्न |
| **परा** |उल्टा, अनादर, नाश |पराजय, परामर्श, पराक्रम |
| **अप** |बुरा, हीनता, विपरीत |अपमान, अपशब्द, अपहरण |
| **सम्** |अच्छी तरह, पूर्णता, संयोग |संकल्प, संतोष, सम्मेलन |
| **अनु** |पीछे, समान, क्रम |अनुशासन, अनुकूल, अनुज |
| **अव** |नीचे, हीनता, पतन |अवनति, अवलोकन, अवसर |
| **निर् / निस्** |बिना, बाहर, अभाव |निर्दोष, निर्जीव, निष्कलंक |
| **दुर् / दुस्** |कठिन, बुरा, हीन |दुर्जन, दुर्दशा, दुष्कर्म |
| **वि** |भिन्नता, अभाव, विशेषता |विज्ञान, विदेश, विकार |
| **आ** |तक, समेत, उल्टा |आदान, आजीवन, आगमन |
| **नि** |भीतर, नीचे, अधिकता |निवास, निबंध, निदान |
| **अधि** |ऊपर, श्रेष्ठ, प्रधान |अधिकार, अधिपति, अध्यादेश |
| **सु** |अच्छा, सहज, सुंदर |सुगम, सुपुत्र, सुगंध |
| **उत् / उद्** |ऊपर, श्रेष्ठ, उत्थान |उत्पन्न, उन्नति, उत्साह |
| **अभि** |सामने, पास, चारों ओर |अभिमान, अभिकथन, अभिलाषा |
| **प्रति** |सामने, हर एक, विरोध |प्रतिदिन, प्रतिकूल, प्रतिध्वनि |
| **परि** |चारों ओर, पूर्णता |परिजन, पर्यावरण, परिमाप |
| **उप** |पास, गौण, सहायक |उपवन, उपमंत्री, उपहार |

### Section 3 | हिंदी के उपसर्ग

संस्कृत के तद्भव शब्दों के साथ विकसित होने वाले ये उपसर्ग मूलतः हिंदी की अपनी प्रकृति से उपजे हैं। इन्हें 'तद्भव उपसर्ग' भी कहा जाता है।

| उपसर्ग |अर्थ / विशेषता |उदाहरण |
| **कद / कु** |बुरा, हीन |कपूत, कुचक्र, कुसंग |
| **नि** |अभाव, रहित |निडर, निकम्मा, निहत्था |
| **भर** |पूरा, ठीक |भरपेट, भरपूर, भरदिन |
| **अध** |आधा |अधमरा, अधकचरा, अधपका |
| **ऊन** |एक कम (संख्या में) |उन्तीस (उन + तीस = 29), उनसठ |
| **बिन** |बिना, रहित |बिनब्याहा, बिनजाने, बिनमाँगा |
| **सह** |साथ, सहचर |सहपाठी, सहोदर, सहकर्मी |
| **दु** |बुरा, हीन |दुबला, दुधारू, दुचत्ती |
| **सु** |अच्छा, सरल |सुजान, सुडौल, सुघर |
| **आ** |अभाव, लेकर |आमुख, आज़ान |

[example]
**प्रश्न:** 'उन्तीस' शब्द में प्रयुक्त उपसर्ग पहचानिए।
**हल:** 'उन्तीस' शब्द में **'ऊन'** उपसर्ग है, जिसका अर्थ 'एक कम' होता है (अर्थात् तीस में एक कम यानी 29)। छात्र अक्सर इसमें 'उन' या 'उ' समझकर गलती करते हैं, अतः मात्राओं की शुद्धता पर विशेष ध्यान दें।
[/example]

### Section 4 | विदेशी उपसर्ग

हिंदी भाषा में अरबी, फ़ारसी और अंग्रेज़ी के प्रभाव से अनेक विदेशी उपसर्ग भी स्थायी रूप से प्रयुक्त होने लगे हैं। ये प्रतियोगी परीक्षाओं में अक्सर भ्रम पैदा करते हैं।

| भाषा |उपसर्ग |अर्थ / विशेषता |उदाहरण |
| **अरबी-फ़ारसी** |**ला** |बिना, रहित |लापरवाह, लाइलाज, लापता |
| **अरबी-फ़ारसी** |**बे** |बिना, अभाव |बेचारा, बेकसूर, बेईमान |
| **अरबी-फ़ारसी** |**बद** |बुरा, हीन |बदनाम, बदकिस्मत, बदबू |
| **अरबी-फ़ारसी** |**कम** |थोड़ा, हीन |कमज़ोर, कमअक्ल, कमसिन |
| **अरबी-फ़ारसी** |**ना** |अभाव, नहीं |नासमझ, नापसंद, नापाक |
| **अरबी-फ़ारसी** |**खुश** |अच्छा, शुभ |खुशखबरी, खुशबू, खुशहाल |
| **अरबी-फ़ारसी** |**हम** |समान, साथ |همसफ़र (हमसफ़र), हमדרद (हमदर्द), हमउम्र |
| **अंग्रेज़ी** |**अन** |विपरीत, नहीं |अनइवेन, अनचाहा (मिश्रित), अनफिट |
| **अंग्रेज़ी** |**नॉन** |निषेध, रहित |नॉनवेज, नॉनस्टॉप |
| **अंग्रेज़ी** |**मल्टी** |अनेक, बहु |मल्टीमीडिया, मल्टीनेशनल |
| **अंग्रेज़ी** |**हाफ** |आधा |हाफपैंट, हाफइंच |
| **अंग्रेज़ी** |**काउंटर** |विरोधी, प्रतिकार |काउंटरअटैक, काउंटर |
| **अंग्रेज़ी** |**प्रो** |पक्ष में, आगे |प्रोग्राम, प्रो-एक्टिव |
| **अंग्रेज़ी** |**एंटी** |विरोधी |एंटीबायोटिक, एंटीसेप्टिक |

### Section 5 | प्रत्यय: परिभाषा, आवश्यकता एवं भेद

=प्रत्यय वे शब्दांश हैं जो किसी शब्द के अंत (Suffix) में जुड़कर उसके अर्थ में विशेषता उत्पन्न करते हैं या उसके व्याकरणिक स्वरूप को बदल देते हैं=।

प्रत्यय के दो प्रमुख भेद होते हैं:

- **कृत प्रत्यय (Primary Suffixes / Kridanta)**
- **तद्धित प्रत्यय (Secondary Suffixes / Taddhita)**

### Section 6 | कृत प्रत्यय (क्रिया के अंत में लगने वाले प्रत्यय)

क्रिया की मूल धातु (Root Form) के साथ जुड़कर नए शब्द (संज्ञा या विशेषण) बनाने वाले प्रत्यय **कृत प्रत्यय** कहलाते हैं और इनसे बने शब्दों को **कृदंत** कहते हैं।

| प्रत्यय |निर्माण प्रक्रिया (धातु + प्रत्यय) |निष्पन्न शब्द |
| **आई** |लिख + आई |लिखाई |
| **आवट** |लिख + आवट |लिखावट |
| **आक** |तैर + आक |तैराक |
| **अक्कड़** |भूल + अक्कड़ |भुलक्कड़ |
| **आहट** |चिल्ल + आहट |चिल्लाहट |
| **आस** |मिष्ट + आस (मीठास) |मिठास |
| **इया** |बढ़ + इया |बढ़िया |
| **हार** |रख + हार |रखवाला / राखनहार |
| **ता** |पढ़ + ता |पढ़ता |
| **ना** |खा + ना |खाना |

### Section 7 | तद्धित प्रत्यय (संज्ञा, सर्वनाम एवं विशेषण के अंत में लगने वाले प्रत्यय)

जो प्रत्यय धातु (क्रिया) को छोड़कर **संज्ञा (Noun), सर्वनाम (Pronoun) और विशेषण (Adjective)** के अंत में जुड़कर नए शब्द बनाते हैं, उन्हें **तद्धित प्रत्यय** कहते हैं।

| प्रत्यय |मूल शब्द + प्रत्यय |निष्पन्न शब्द |विशेषता / अर्थ |
| **आई** |अपना + आई |अपनापन / अपनाई |भाववाचक संज्ञा |
| **आलू** |दया + आलू |दयालु |विशेषता बोधक |
| **अक / का** |लेखक (लेख + अक) |लेखक |कर्ता बोधक |
| **आस** |खट्टा + आस |खटास |गुण/भाव बोधक |
| **इया** |कलकत्ता + इया |कलकत्तिया |स्थान बोधक |
| **एला** |जहर + एला |जहरीला |युक्त होने का भाव |
| **पन** |बाल + पन |बचपन |भाववाचक संज्ञा |
| **मान** |बुद्धि + मान |बुद्धिमान |विशेषता बोधक |

### Section 8 | उपसर्ग एवं प्रत्यय में मुख्य अंतर

परीक्षार्थी अक्सर उपसर्ग और प्रत्यय के तकनीकी अंतर में भ्रमित हो जाते हैं। इसे स्पष्ट रूप से समझने के लिए निम्नलिखित तालिका का अध्ययन करें:

| आधार |उपसर्ग (Prefix) |प्रत्यय (Suffix) |
| **स्थान (Position)** |यह शब्द के **आरंभ** में जुड़ता है। |यह शब्द के **अंत** में जुड़ता है। |
| **प्रकृति (Nature)** |यह मूल शब्द के अर्थ को एक नई दिशा या विपरीत अर्थ देता है। |यह शब्द की जाति (संज्ञा, विशेषण आदि) या उसका व्याकरणिक रूप बदलता है। |
| **स्वतन्त्रता** |यह एक पूर्वाधिकारी शब्दांश है। |यह एक पश्चगामी (Trailing) शब्दांश है। |

### Section 9 | त्वरित स्मरण फ्लैशकार्ड्स

[flashcards title="उपसर्ग एवं प्रत्यय महत्वपूर्ण तथ्य"]
| शब्दांश प्रकार | मूल अंतर | मुख्य परीक्षा उदाहरण |
| उपसर्ग | शब्द के पूर्व में जुड़ना | 'प्रतिकूल' में 'प्रति' उपसर्ग |
| प्रत्यय | शब्द के अंत में जुड़ना | 'पढ़ाकू' में 'आकू' प्रत्यय |
| कृदंत | क्रिया धातु से निर्मित शब्द | 'लिखावट' (लिख + आवट) |
| तद्धित | संज्ञा/विशेषण से निर्मित शब्द | 'बचपन' (बाल + पन) |
[/flashcards]

### Section 10 | अभ्यास प्रश्नावली (Quiz)

Q: 'सुशिक्षित' शब्द में प्रयुक्त उपसर्ग एवं मूल शब्द का सही विकल्प कौन सा है?

- A) सु + शिक्षित (Correct: यहाँ 'सु' उपसर्ग और 'शिक्षित' मूल शब्द है।)
- B) सुशि + क्षित
- C) सू + शिक्षित
- D) सुशि + शक्षित

Q: निम्नलिखित में से किस शब्द में 'इया' प्रत्यय का प्रयोग नहीं हुआ है?

- A) बढ़िया
- B) घटिया
- C) मुखिया
- D) अड़ियल (Correct: 'अड़ियल' में 'इयल' प्रत्यय का प्रयोग हुआ है, 'इया' का नहीं।)
[/quiz]
