They test your ability to manipulate letters—rearranging them, identifying their positions, and understanding their relationships within a word. The core skills are vocabulary knowledge, spatial reasoning with letters, and systematic pattern recognition.The fundamental insight is that every word formation problem reduces to a question about letter positions and arrangements. The key is understanding how dictionary ordering works.The Dictionary Order Rules:First Letter: Compare the first letters. The word with the earlier letter (A before B) comes first.Second Letter: If the first letters are the same, compare the second letters.Continue: Continue this process until a difference is found or one word ends.Shorter Word First: If one word is a prefix of the other, the shorter word comes first (e.g., "CAT" before "CATCH").The Ranking Protocol:List All Permutations: For a set of letters, list all possible arrangements.Sort Alphabetically: Sort the arrangements in dictionary order.Find the Position: Identify the position of the target word.[alert type="danger"]The "Permutation Count" Trap:When ranking words, you often need to count how many words come before the target word. This requires careful permutation counting. For example, if the first letter is fixed, the number of arrangements of the remaining letters is (remaining letters)!.[/alert][example]Question: What is the position of the word "CAT" in a dictionary containing all possible arrangements of the letters C, A, T?(A) 2(B) 3(C) 4(D) 5Solution:1.
